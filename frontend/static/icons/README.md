# SVG icon slot

Place product-specific SVG icons here only after the interaction and visual role is confirmed.

Rules:
- Prefer simple inline/currentColor SVGs with a consistent viewBox (recommended `0 0 24 24`).
- Do not generate icons merely to decorate empty space.
- Future image-generation/image2 output may be used as a draft source, but every icon must be manually reviewed before inclusion.
- Icon meaning must remain stable across Situation / Indicator / Run / Results / GIS.
- Keep text labels for important actions; icons should not be the sole carrier of meaning for destructive or uncommon actions.
