# F0/F1 真实浏览器视觉与交互验收清单

后续 Codex/人工在 Flask + 本地资产就绪后执行。

## 窗口档位
- 1366×768
- 1672×941
- 1920×1080

## 所有页面
- Topbar/Sidebar 尺寸一致，不覆盖主工作区。
- 没有横向页面级溢出；需要宽表时只在表格容器内部滚动。
- 文字不低于当前设计下限；辅助文字可读，不出现大面积 8–9px 小字。
- 同一业务组间距紧，跨业务组间距明显增大；不存在所有组件统一大 gap。
- 空态、loading、error 出现时容器骨架不大幅跳变。
- popover/dock/overlay 打开和关闭不推动主页面布局。
- 键盘焦点/ESC/点击外部等关闭行为按最终组件规范复核。

## Run
- 1366 高度下配置区可独立滚动，队列/历史仍可到达。
- 高级设置与校验展开/关闭无突然高度跳变。
- 只显示阶段 X/4，不出现推测百分比。
- 日志 8–12 行左右、内部滚动；自动滚动关闭后不会把用户拉回底部。
- 查看历史日志期间 live polling 不替换被查看对象。
- viewer 看不到或不能执行运行/重试动作。

## Single Run
- 五摘要在 1366 宽度下不互相挤压到不可读。
- 中部和底部随着数据量变化使用内部滚动/自然高度，不按示例行数撑布局。
- “组群与航链结构”明确显示非比例示意，不暗示真实地理距离。
- 详情 Dock 覆盖主内容，关闭后恢复原滚动位置。

## GIS Runtime
- 左侧控制、右侧速览、底部时间轴互不遮挡。
- 详情 Dock 打开时速览淡出，不形成两块竞争详情面板。
- 运行范围/全部范围按钮实际改变地图视野。
- 状态强调关闭只改变符号强调，不隐藏机场本身。
- 多条相同/相近 OD 曲线可辨；活跃虚线动画不被理解为航空器实时移动。
- 本地 Leaflet 缺失时显示明确空态；就绪后不请求 CDN。

## Results
- 三工作区切换无结构跳变。
- 主图 hover tooltip 能读取具体时间窗与每条系列数值。
- 比较条件 overlay 打开时背景不被压缩。
- 1366 下主图与差异概览可纵向重排，底部完整数据仍可访问。
- PDF/CSV 导出只在权限允许时启用。
