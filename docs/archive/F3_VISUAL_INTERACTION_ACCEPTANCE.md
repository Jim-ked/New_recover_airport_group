# F3 Indicator 真实浏览器验收清单

在本地 Flask 环境启用后检查：

1. 进入“指标管理”默认打开 `默认指标集 V1.1`，不闪现空树。
2. 3 个一级节点完整；切换一级后只展示其二级；切换二级后只展示其三级，58 个三级节点不会一次堆满页面。
3. 1366×768 下顶部指标集选择、树区、右侧工作区均可使用；内容多时只在对应工作区滚动，不裁掉底部动作。
4. 默认指标集不出现节点编辑动作；核心三级节点有明确受保护标记。
5. 新建指标集弹层默认以系统默认集为来源，也可选择其他已发布自建集；创建后立即进入独立草稿。
6. 发布自建指标集后，重新进入模块仍默认打开系统 V1.1；下拉列表中自建集仍可选择。
7. 草稿中新增/编辑/启停普通三级指标后保持当前一级/二级上下文，不跳回第一组。
8. 专家评分切换二级分组时已填写值不丢失；提交按钮仅在全部启用三级指标均已评分时可用。
9. 保存 draft 后权重不应因草稿输入而被描述成已提交事实；submitted 后权重显示更新。
10. viewer 只读；operator 可评分但不能改指标结构/专家；admin 才能维护结构和专家。
11. 弹层展开/关闭、树选择、右侧页签切换无大面积布局跳动，间距遵循 F0 语义 spacing。
12. 页面不展示运行结果指标值，不出现算法参数编辑。
