# F2 真实浏览器视觉/交互验收清单

后续 Codex 配好 Flask、Leaflet、本地瓦片与素材后执行。当前静态检查不能替代此清单。

## Situation

- 1366×768 / 1672×941 / 1920×1080 下顶部情境栏、工具条、搜索、右 inspector、底部 overview 不互相遮挡。
- inspector 关闭后 overview 右侧空间自然扩展，不遗留大块死空白。
- overview 展开/收起不推动地图工作区，不出现高度跳变。
- 机场候选数量 0 / 5 / 50 / 500 时，右栏只内部滚动，不拉高页面。
- 名称/编号、类型、区域筛选后地图候选与列表完全一致。
- 列表勾选候选时地图高亮同步；地图点击候选时列表同步。
- 右侧机场/任务/损毁编辑器有长内容时 footer 保持可达，不覆盖最后一行输入。
- 编辑器草稿离开提示与 Working Copy 未保存提示不得重复弹出或互相混淆。
- viewer 打开机场/任务详情时字段明确只读，不能产生 Working Copy dirty。
- Leaflet 缺失时无底图坐标视图可用且不会被误认为真实底图。
- 真实 Leaflet 就位后地图取点、marker、标签、damage ring 在深色底图上可辨认。

## Base Data

- 四个页签切换不产生布局跳变。
- 30 行列表、长机场名、长区域名、长资源单位时表格不破版。
- 机场跑道结构展开后详情区内部滚动正常；多个跑道不把整个页面无限拉长。
- 新增/编辑表单在 1366×768 下保存/取消始终可达。
- 未保存编辑时切页签、搜索、筛选、翻页、点其他记录均出现一次明确确认。
- 覆盖导入窗口在错误 JSON、错误 CSV、后端字段错误时保持打开并显示具体错误。
- 导入成功后列表、数量、详情状态正确刷新。
- 深链 `/base-data?tab=airports&id=...` 能定位并打开对应机场。
- viewer 不显示可执行的新增/编辑/删除/覆盖导入状态。

## 视觉节奏

- 同一字段内部 4–8px，强关联块约 8–12px，业务组之间约 14–20px；不得机械等距。
- 正文/表格 11–12px 为主，10px 仅用于辅助说明、元信息和 badge。
- 禁止新增 8–9px 文本。
- 右栏、Modal、overview 动画使用统一 F0 motion token，不单独设置突兀时长。
